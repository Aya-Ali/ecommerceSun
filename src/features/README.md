# Feature modules

Keep feature-specific UI, types, hooks, and data access together here. App Router files in `src/app` should stay thin and compose these modules.

- `account`: addresses, profile settings, wishlist, and order history
- `auth`: sign in, sign up, forgot/reset password, and reset-code verification
- `cart`: cart state and line items
- `catalog`: products, product details, categories, brands, and search
- `checkout`: delivery and order review
- `home`: storefront landing content
